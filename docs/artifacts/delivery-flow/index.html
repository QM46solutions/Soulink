Soulink Delivery Flow

How Soulink gets from the laptop to a phone

From the Soulink folder on your laptop to the app on a user's phone. Everything after your push runs in the cloud by itself.

Step by step

  1. Develop on the laptopClaude writes the code in your Soulink folder (C:\Users\Sai raghava\Documents\Soulink). The mobile folder is the phone app; server is the server.
  2. Check it on the laptopUPDATE-SOULINK.bat installs new packages and updates the database tables. RUN-TESTS.bat checks that nothing broke.
  3. Push with GitHub DesktopCommit + Push sends the code to GitHub (QM46solutions/Soulink, branch main). This is the only thing you do after testing.
  4. GitHub's robots take over"Build Soulink for the cloud" packs the server and website and Render puts them online (about 5 minutes). "Soulink phone app" sends the new app code to Expo as an over-the-air update.
  5. Server and database answer the appRender runs the server the app talks to (logins, posts, Sparks, chats, Soul DNA, notifications). Azure SQL stores everything, including photos and videos.
  6. New app versions, only when neededFor a new permission or a version for the stores, tap Run workflow on GitHub. Expo builds the Android and iPhone app files and sends them to the Play Store and the App Store / TestFlight.
  7. On the user's phoneThe user installs Soulink once from the store. After that, each time it opens it quietly downloads the latest code from Expo, talks to the Render server for data and live chat, and gets notifications through Apple / Google.
